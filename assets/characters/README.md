Baby Yoda voice reference

`baby-yoda-reference.mp3` is the user-provided “Baby babble” recording by bvaudio, distributed via Pixabay under the Pixabay Content License:
https://pixabay.com/sound-effects/people-baby-babble-70664/

`baby-yoda-reference-short.mp3` is a 10-second opening segment used server-side for Higgs TTS voice reference to reduce overlong babbling. The sample itself contains no intelligible words, so replies include short text plus at most one brief “ba” vocalization. Higgs Avatar animates the resulting speech audio.

Kevin character assets

`public/characters/kevin.jpeg` is the current Kevin portrait supplied by the project owner. `kevin-reference.mp3` is the supplied voice sample. The portrait is sent to Higgs Avatar for talking clips, and the sample is used as Higgs TTS reference audio. Kevin has an original playful sidekick personality and does not quote movie dialogue. `public/characters/kevin.webp` is an older portrait and is no longer the default.
